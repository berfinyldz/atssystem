# ATS System

An **Applicant Tracking System (ATS)** web application developed with ASP.NET Core MVC to help companies manage job postings and recruitment processes.

> **Status:** In development

## Project Purpose

The main goal of this project is to build a web-based system where companies can create and publish job postings, while HR teams can manage applications and recruitment processes.

## Technologies

* C#
* ASP.NET Core MVC
* Entity Framework
* SQL Server
* HTML
* CSS
* Bootstrap
* JavaScript

## Current Features

* Job listing
* Job detail pages
* Job search
* Department and employment type information
* HR portal
* Custom HR portal layout and navigation
* Retrieving job postings from the database

## Planned Features

## Installation

Clone the repository:

```bash
git clone <repository-url>
```

Navigate to the project directory:

```bash
cd atssistem
```

Configure the SQL Server connection and install the required NuGet packages.

Run the application:

```bash
dotnet run
```
